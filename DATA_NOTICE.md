# Data Notice

## Synthetic data only

This repository contains only fabricated records created for an educational Databricks portfolio project. It does not contain protected health information (PHI), personally identifiable information, real member records, real pharmacy transactions, or data from any healthcare organization.

The fictional member keys, plan information, medication events, enrollment intervals, and refill patterns exist only to demonstrate medication adherence analytics concepts.

## Permitted use

Use the included data and code for learning, demonstration, portfolio review, and experimentation. Do not use the results for clinical decisions, member outreach, benefit administration, or official quality reporting.

## Important limitations

- The medication mappings and PDC rules are simplified for demonstration.
- The results are not an official CMS Stars calculation.
- Any production implementation would require current approved specifications, formal data governance, validated source transaction linkage, security review, and authorized human oversight.
