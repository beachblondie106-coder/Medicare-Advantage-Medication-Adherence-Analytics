# Data Folder

The local project includes CSV extracts used during development. They contain only fictional, synthetic records created for this portfolio project.

The runnable Databricks notebook generates the same demo source tables directly in the Databricks workspace. For that reason, the raw CSV extracts are not required to reproduce the project and are not included in this repository.

See [DATA_NOTICE.md](../DATA_NOTICE.md) for the synthetic data and appropriate use statement.
